# UNU Genius 2026 — Project Rules & Stack

## Tech Stack
* **Frontend Framework:** Vue 3 (Composition API `<script setup lang="ts">`)
* **Build Tool:** Vite 6 + `@tailwindcss/vite`
* **Routing:** Vue Router 4 (HTML5 History Mode)
* **State Management:** Pinia (`@/store/gameStore.ts`)
* **Icons:** `@phosphor-icons/vue`
* **Styling:** Tailwind CSS v4 (`@/style.css`) + Stardew Valley Retro RPG Theme
* **Target Audience:** Mahasiswa Baru UNU Yogyakarta 2026 (Orientasi PKKMB 2026)
